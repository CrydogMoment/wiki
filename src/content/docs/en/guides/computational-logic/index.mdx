Binary is the foundation of every computer's operation, be it a mobile phone, an ECU in a car, or the largest supercomputer in the world. 

## What is binary? 

On its own, binary can look quite confusing as a seemingly random collection of ones and zeroes, but to a computer it is just like reading plain text.
Binary is just another way of representing a number. While we represent numbers using a combination of 0-9, binary only uses 0 and 1. 

:::tip [How is it stored then?] 
In a computer, a 1 is stored as a HI voltage (anything above zero volts), and a zero as a LO voltage (zero volts).
:::

## What is a logic gate? 


### **NOT GATE**

A NOT gate is exactly as it sounds, it outputs the opposite of whatever goes in.  

| A 	| OUT |
|---	|---	|
| 0 	| 1 	|
| 1 	| 0 	|

### **AND GATE** 
| A 	| B 	| OUT |
|---	|---	|---	|
| 0 	| 0 	| 0 	|
| 1 	| 0 	| 0 	|
| 0 	| 1 	| 0 	|
| 1 	| 1 	| 1 	|

### **OR GATE** 
| A 	| B 	| OUT |
|---	|---	|---	|
| 0 	| 0 	| 0 	|
| 1 	| 0 	| 1 	|
| 0 	| 1 	| 1 	|
| 1 	| 1 	| 1 	|

### **XOR GATE **
